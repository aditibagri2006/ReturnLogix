# ReturnLogix

An AI-powered Return Management System built during internship.

## Features

- Customer Portal
- Employee Portal
- AI-based Return Status Prediction
- Dashboard Analytics
- Search & Filters
- Export CSV
- Export Excel
- Print Reports
- Return Tracking
- Image Support

## Tech Stack

### Frontend
- React.js
- CSS

### Backend
- Flask
- Python

### Database
- PostgreSQL

### Machine Learning
- Scikit-learn
- Pandas

## Installation

### Clone Repository

```bash
git clone https://github.com/aditibagri2006/ReturnLogix.git
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm start
```

Application runs on:

- Frontend: http://localhost:3000
- Backend: http://localhost:5000
